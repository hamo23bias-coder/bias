# Bias Tech Platform API

Backend API for the Bias Tech personal portfolio and services site. Handles authentication, leads/CRM, blog, portfolio, analytics, and AI Studio.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server locally (requires PORT env var)
- `pnpm run typecheck` — full typecheck across all packages (must pass before deploying)
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes to Supabase

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5 (artifacts/api-server)
- DB: Supabase PostgreSQL + Drizzle ORM (lib/db)
- Validation: Zod v3 via @workspace/api-zod (generated by Orval from OpenAPI spec)
- DB Types: Native Drizzle `InferInsertModel` (drizzle-zod removed — caused zod v3/v4 conflict)
- API codegen: Orval (from lib/api-spec/openapi.yaml)
- Build: esbuild (CJS/ESM bundle via artifacts/api-server/build.mjs)

## Where things live

- `artifacts/api-server/src/routes/` — Express route handlers
- `artifacts/api-server/src/lib/` — JWT, email, cron, seed utilities
- `artifacts/api-server/src/middlewares/auth.ts` — JWT auth middleware
- `lib/db/src/schema/` — Drizzle table definitions (no drizzle-zod, use InferInsertModel)
- `lib/api-zod/src/generated/` — Zod schemas generated by Orval from OpenAPI spec
- `lib/api-spec/openapi.yaml` — OpenAPI spec (source of truth for API contracts)
- `api/index.mjs` — Vercel serverless entry point (imports from dist/app.mjs)
- `vercel.json` — Vercel deployment config

## Architecture decisions

- **drizzle-zod removed**: Was causing zod v3/v4 type conflicts. Replaced with native `InferInsertModel<typeof table>` from drizzle-orm for insert types.
- **Vercel pre-build approach**: Instead of letting Vercel compile TypeScript (which used node16 moduleResolution and required explicit .js extensions), we run esbuild during buildCommand to produce dist/app.mjs, then api/index.mjs imports the pre-built bundle.
- **Supabase Pooler**: Using the Supabase connection pooler URL (pooler.supabase.com) for serverless compatibility.

## Gotchas

- Always run `pnpm run typecheck` before pushing — fixes must pass zero errors
- Do NOT re-add drizzle-zod to lib/db — use native Drizzle types instead
- Always run `git config user.name/email` locally before any commit
- `dist/` is in .gitignore — Vercel builds it fresh from the buildCommand
- esbuild version pinned to 0.27.3 via pnpm-workspace.yaml overrides
